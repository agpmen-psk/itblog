О проекте

Интернет-магазин с новостным разделом на Django.

IT-блог и магазин

Проект объединяет каталог товаров, корзину, оформление заказов и новостной блог в одном Django-приложении с авторизацией пользователей и административной панелью.

Технологии

  • 🐍 Python + Django
  • 🗄️ SQLite / PostgreSQL
  • 🎨 Собственный CSS без Bootstrap
  • 👤 Авторизация и группы пользователей
  • 🛒 Корзина и оформление заказов
  • 📝 Блог с комментариями
  • ⚙️ Django Admin

Что умеет проект

🛍️ Магазин

Каталог с категориями, карточки товаров, корзина, оформление и история заказов для каждого покупателя.

📰 Блог

Публикации с изображениями, система комментариев для авторизованных пользователей.

👤 Аккаунты

Регистрация, вход, личный кабинет с историей заказов, разграничение прав через группы Django.
